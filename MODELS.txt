# 模型清单：容器启动时按此清单自动下载缺失的模型
# 格式（用 | 分隔）：
#   仓库ID | 文件名 | ComfyUI/models 下的子目录 | sha256（可选，留空则只判断文件存在）
#
# 子目录对照 ComfyUI 习惯：
#   checkpoints = 文生图主模型 / unet|diffusion_models = 分块权重
#   vae / loras / controlnet / clip / clip_vision / upscale_models ...
#
# 行首加 # 即注释掉（不会下载）。正式用时把示例换成主人实际要用的模型，
# 建议填上 sha256（在 HF 仓库文件页可查），防止下到损坏文件。

# ---- 示例（占位，主人定好模型后替换） ----
